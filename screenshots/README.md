# Bolt Browser screenshots

Add screenshots to this folder and commit them to the `main` branch. Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`, and `.gif`.

The public `sponsor.html` page automatically reads this folder through GitHub's public Contents API and displays supported image files in its Screenshots gallery. No HTML edits are needed when adding or removing images; refresh the page after the new commit is published.

Tips:
- Use descriptive filenames (for example, `tab-groups.png`). The filename is shown as the image caption.
- Prefer optimized images so the gallery loads quickly.
- Do not upload private information, personal data, or images you do not have permission to publish.

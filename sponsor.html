Meet Bolt Browser.

A browser built for everyday browsing, with useful tools for people who like to build for the web. If you enjoy the project, try it out and share it.

Security & Transparency Notice

Bolt Browser is an independent, open-source project that is still developing. No independent third-party security audit has been completed. Although the source code and build workflows are publicly available for inspection, undiscovered vulnerabilities may still exist.

Web browsers handle sensitive information, including passwords, cookies, browsing sessions, and browsing history. Please consider this before using Bolt for sensitive activities.

We encourage security researchers and developers to review the source code and responsibly report vulnerabilities through our security policy. Transparency and security improvements are ongoing priorities for Bolt Browser.

A browser project you can inspect
